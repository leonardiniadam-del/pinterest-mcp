# Privacy policy

Last updated: November 20, 2026

This app is a personal tool. It connects one person's own Pinterest account to that person's own
computer, so they can read their boards and pins, save pin images for their own research, create
boards, and pin images to their own boards.

**Who uses it.** Only the owner of this project, with their own Pinterest account. It is not
offered to the public and has no other users.

**What data it reads.** Through Pinterest's official API, and only with the owner's permission:
the owner's account name, boards and pins, and the images on those pins.

**What it stores.** Images the owner chooses to save are kept on the owner's own computer. The
access token is kept in a local file on that computer and is never shared or uploaded. Nothing is
sent to any server other than Pinterest's own.

**What it does not do.** It does not collect, store, sell or share data about any other Pinterest
user. It does not track anyone, show ads or use analytics.

**Removing access.** The owner can end the app's access at any time by revoking it in their
Pinterest account settings or by deleting the local token file.

**Contact.** Questions about this app can be raised as an issue on this GitHub project.
